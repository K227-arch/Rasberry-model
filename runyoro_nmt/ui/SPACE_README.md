# AI Stick — Runyoro-Rutooro ↔ English Translator

Bidirectional neural machine translation for **Runyoro-Rutooro** (western Uganda)
and **English**, powered by **runyoro-nmt-v1** fine-tuned on NLLB-200.

Model: [kathay/runyoro-nmt-v1](https://huggingface.co/kathay/runyoro-nmt-v1)
Dataset: [kathay/runyoro-rutooro-en-parallel](https://huggingface.co/datasets/kathay/runyoro-rutooro-en-parallel)
